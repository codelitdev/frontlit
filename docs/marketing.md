# Marketing

## Problems we are solving
- Build and manage your marketing website, product documentation, changelogs, blogs etc., using an Agent first platform. Everything the UI can do can be done via API/MCP.
- All the above feeds into a common knowledge base which your bot needs in order to answer product support questions is under one roof
- A documentation site that stays closer to your code so the the [drift](https://www.reddit.com/r/SaaS/comments/1se4cvz/your_ai_support_bot_is_only_as_current_as_your/) between code and documentation can be reduced by using AI agents manage the documentation.
