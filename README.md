# Introduction

Website builder, Blog, Help Desk, Email Newsletter, Chatbot, Changelog, all rolled into one.

The front office of your SaaS.

API first. AI ready (MCP compatible)

## Tech stack

- ts-rest (for API)
- PostgreSQL (For DB and vector search)
- Next.js
- Tailwind CSS
- Shadcn UI
- Drizzle ORM
- fumadocs (with openapi extension) for docs
