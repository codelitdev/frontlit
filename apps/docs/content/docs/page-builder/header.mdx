## Usage

`header` and `footer` are layout blocks — the renderer pins them to the top/bottom regardless of their position
in the `layout` array:

```tsx
import { createWidgetInstance, PageRenderer, getDefaultTheme } from "@frontlit/page-builder";

const layout = [createWidgetInstance("header", { ctaHref: "/get-started" })];

<PageRenderer layout={layout} theme={getDefaultTheme()} pageData={{ pageType: "landing" }} />;
```
