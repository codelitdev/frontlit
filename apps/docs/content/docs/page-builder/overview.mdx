title: Overview
description: The block-based WYSIWYG page builder and renderer.
---

`@frontlit/page-builder` is a block-based WYSIWYG page builder and renderer for React/Next.js. A page is a `Theme`
plus a `WidgetInstance[]` layout; each widget is one block from the registry (hero, header, footer, pricing, faq,
grid, rich-text, email-form, and more).

```bash
pnpm add @frontlit/page-builder
```

```tsx
import { PageBuilder } from "@frontlit/page-builder";

export default function Editor() {
    return <PageBuilder pageData={{ pageType: "landing" }} />;
}
```

The pages that follow demo each block individually, and the full `<PageBuilder>` editor at the end.
