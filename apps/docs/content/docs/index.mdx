FrontLit is the frontoffice of your SaaS: a block-based WYSIWYG page builder (`@frontlit/page-builder`) paired
with a REST/OpenAPI/MCP API for managing teams, pages and themes programmatically.

- **[Getting Started](/getting-started/overview)** — set up the API and web app locally.
- **[Self-hosting](/self-hosting)** — run SendLit and its dependencies with Docker Compose.
- **[Components](/components/page-builder)** — install and use `@frontlit/page-builder` and `@frontlit/text-editor`.
- **[Developers](/developers/overview)** — authentication, teams, and API keys.
- **[API Reference](/api-reference)** — the full REST API, generated from the same contract the server validates against.
